# Ashish Singh — Portfolio

## Files
- `index.html`: portfolio content and navigation
- `style.css`: responsive dark design
- `profile.jpg`: add your own portrait photo using this exact filename

## Add your photo
1. Choose a clear, professional portrait.
2. Rename it to `profile.jpg` (all lowercase).
3. Upload it to the same repository folder as `index.html` and `style.css`.
4. If your photo has a different filename, change `src="profile.jpg"` in `index.html`.

The portfolio works without the photo, but the photo card will show an “Add your photo” fallback.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Set the source to **Deploy from a branch**, select `main` and `/ (root)`, then save. Wait a few minutes for publishing.

## Contact and profile links
The email and public profile URLs are included in `index.html`. Update them if any link changes.
